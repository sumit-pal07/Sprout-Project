Screen 1 — Welcome · design notes

  • Opens with the user's own words. 65% of surveyed users said "investing feels scary" — the headline mirrors it back, then reframes. Trust starts with being heard.
  • Beej's introduction sets the continuous story: the same seedling from the homepage now speaks. Geometric, premium — the CEO's "no cartoon" rule survives.
  • EN/हिं toggle is a prototype of Hindi-readiness: strings swap via a dictionary; no layout change, no text baked into images, generous line lengths absorb longer Devanagari.
  • Single CTA, 52px tall. Disclaimer rides along in the sticky bar from screen one.
